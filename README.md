# Data Cleaning & Visualization

## Overview
This project focuses on building a simple but structured pipeline for cleaning and analyzing raw sales data. The dataset contains missing and inconsistent values, which are handled before performing basic analysis and generating visualizations.

The goal here is to demonstrate a clean approach to preprocessing and extracting useful insights from a small dataset.

---

## Tech Stack
- Python
- Pandas
- Matplotlib
- Seaborn

---

## What’s implemented
- Data loading with basic validation
- Handling missing values (mean/median strategy)
- Type conversion for date and numeric fields
- Feature creation (`total_sales`)
- Aggregation of sales by product
- Visualization of results
